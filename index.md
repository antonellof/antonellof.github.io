👋 Hello world.

I'm an AI Cloud Engineer and Architect interested mostly in HPC, LLM inference, Agentic AI and Cloud.

My open-source projects include [Cognitora inference](https://github.com/antonellof/cognitora-inference) (KV-aware LLM orchestration above vLLM, SGLang, TensorRT-LLM and llama.cpp), [Frink](https://github.com/antonellof/frink) (a pure-Rust GGUF engine), [GPUlayer](https://www.gpulayer.dev/) (PyTorch on any GPU you can reach) and [puglia-wind](https://github.com/antonellof/puglia-wind) (OpenFOAM wind flow over Puglia, built from source with Spack on GCC and AMD AOCC, run with MPI, [3D viewer](https://www.fratepietro.com/puglia-wind/)).

This blog is where I write about HPC, cloud architecture, inference, GPUs, distributed systems and engineering leadership.

🕹️ Learned to code on a Commodore, and I've basically been hitting RUN ever since.
