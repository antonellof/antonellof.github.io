👋 Hello world.

I'm an AI Cloud Engineer and Architect interested mostly in LLM inference, HPC application performance, Agentic AI and Cloud.

My open-source projects include [Cognitora inference](https://github.com/antonellof/cognitora-inference) (KV-aware LLM orchestration above vLLM, SGLang, TensorRT-LLM and llama.cpp), [Frink](https://github.com/antonellof/frink) (a pure-Rust GGUF engine) and [GPUlayer](https://www.gpulayer.dev/) (PyTorch on any GPU you can reach). Lately I've been building and tuning HPC codes from source on AMD EPYC and Instinct: [toolchains](https://github.com/antonellof/epyc-toolchain-study), [WRF](https://github.com/antonellof/wrf-epyc) and [LAMMPS](https://github.com/antonellof/md-epyc-instinct).

This blog is where I write about cloud architecture, inference, GPUs, HPC, distributed systems and engineering leadership.

🕹️ Learned to code on a Commodore, and I've basically been hitting RUN ever since.
